injection
=========

Shared types for the agent injection contract. These types are
backend-neutral: they name the surfaces a target draws untrusted content
from, the plans that describe what an injector does to those surfaces,
the routes a generator applies, and the evidence an injection execution
produces. Transport details belong to the injectors and generators,
never to these definitions.
