garak.probes.hiddencontext
=================================

This probe tests the model on the context exposure. As per the `OWASP 2026 LLM Top 10 <https://genai.owasp.org/resource/owasp-genai-llm-top-10-2026/>`_ Hidden content exposure is placed at 8th.
It is defined as "the unauthorized extraction, inference, or reconstruction of hidden, non-user-facing system instructions or operational context placed in a model's context."
